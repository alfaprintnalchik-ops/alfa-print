# АЛЬФА — светлая двуязычная версия

Что изменено:
- светлый премиальный дизайн;
- переключатель RU / EN в шапке;
- фиксированная кнопка «Позвонить» внизу справа, всегда видна при прокрутке;
- кнопка размещена с учётом safe-area на современных телефонах;
- адаптация под мобильные телефоны, планшеты и ПК;
- аватар/логотип остаётся локальным файлом;
- сайт полностью статический и готов для GitHub Pages.

## Запуск
Откройте `index.html`.

## GitHub Pages
Загрузите все файлы в корень репозитория → Settings → Pages → Deploy from branch → `main` / `/root`.
