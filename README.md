# АЛЬФА — насыщенный premium-сайт в стиле крупных типографий

Готовая статическая версия сайта для **АЛЬФА** с акцентом на сильный первый экран, насыщенную структуру и приятные анимации.

## Что сделано
- главный экран в стиле крупных сайтов типографий;
- адаптация под **телефон, планшет и ПК**;
- мягкие анимации при прокрутке;
- переключение **RU / EN**;
- финальный блок с контактами, WhatsApp, Telegram, звонком и адресом;
- изображения подготовлены локально и лежат в папке `assets`;
- сайт готов к загрузке на **GitHub Pages**.

## Как открыть
Откройте `index.html`.

## Как загрузить на GitHub
Загрузите в корень репозитория:
- `index.html`
- `README.md`
- `SOURCES.md`
- `.nojekyll`
- папку `assets`

После этого в **Settings → Pages** выберите:
- **Deploy from a branch**
- ветка **main**
- папка **/(root)**

## Структура
- `index.html` — сайт
- `assets/styles.css` — стили
- `assets/script.js` — меню, анимации, RU/EN
- `assets/*.webp` — локальные изображения
- `assets/avatar-alpha.webp` — аватар/логотип
- `assets/favicon.svg` — иконка
